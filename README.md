# 🏢 TileShop - Premium Tiles E-commerce

A modern, responsive e-commerce platform built with Next.js for browsing and managing premium tile collections. This project features secure authentication, dynamic profile management, and a mobile-first design.

## 🔗 Live URL
[View Live Site](https://tiles-gallery-murex.vercel.app)*

## 🚀 Purpose
TileShop was developed to provide a seamless user experience for customers looking to explore high-quality tiles. The goal was to implement a full-stack application with robust authentication, clean UI/UX, and optimized image handling.

## ✨ Key Features
*   **Secure Authentication:** Powered by Better-Auth for seamless login/logout and session management.
*   **User Profiles:** Dedicated profile pages for users to view and update their information.
*   **Responsive Navbar:** A custom-built, mobile-first navigation bar using Tailwind CSS with `flex-col` transitions.
*   **Dynamic Image Optimization:** High-performance image rendering using Next.js `next/image`.
*   **Production Ready:** Configured with remote patterns and environment variables for deployment.

## 🛠️ NPM Packages Used
The following key libraries and tools were used in this project:

| Package | Purpose |
| :--- | :--- |
| **Next.js** | React framework for SSR and routing |
| **Better-Auth** | Authentication client and session management |
| **Tailwind CSS** | Utility-first CSS framework for styling |
| **Lucide-React** | Modern, lightweight icons |
| **React Loader Spinner** | Visual feedback during data fetching |
| **Clsx / Tailwind-Merge** | Managing dynamic class names |
